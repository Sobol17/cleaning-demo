# Ясно — демо клининговой компании

Онлайн-демо: https://sobol17.github.io/cleaning-demo/

Публикация через GitHub Pages из корня ветки `main`.

## Запуск

Откройте `index.html` двойным щелчком в Chrome, Edge или Safari. Весь прототип находится в одном HTML: стили Tailwind CSS 4, JavaScript, GSAP, шрифты и фотографии встроены. Интернет, установка пакетов и сборка не нужны.

Данные сохраняются в localStorage текущего браузера. Для демонстрации используйте один браузер и обычный режим, не приватный. При переносе HTML на другой компьютер история не переносится. При недоступном или заполненном хранилище появится уведомление.

Если браузер ограничивает хранилище для локальных файлов, запустите из папки проекта:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080. Хранилища у локального файла и адреса localhost отдельные.

## Сценарий показа за 5 минут

1. На сайте нажмите «Получить расчёт». Заполните площадь, имя и демонстрационный телефон из 11 цифр, начиная с 7 или 8. Отправьте форму: появится номер заявки.
2. Верхним переключателем откройте CRM. Новая заявка находится в первом столбце. Откройте её, уточните адрес, укажите согласованную стоимость и назначьте бригаду. Для свободного времени можно выбрать следующий день после демонстрационной даты, 14:00. Статус — «Запланирована».
3. В карточке нажмите «Чек-лист и фото», затем «Начать уборку». Отметьте все работы и загрузите фото до и после. Нажмите «Завершить уборку». Можно показать тот же сценарий через роль «Бригадир», выбрав назначенную бригаду.
4. Откройте завершённую заявку и нажмите «Повторить уборку». Создастся новая заявка через неделю, без назначенной бригады и без согласованной стоимости.
5. В «Партнёрах» измените текст баннера. Нажмите «Посмотреть баннеры на сайте». Отключённые и истёкшие размещения скрываются.
6. В «Продвижении» выберите материал, подготовьте демо-черновик, отредактируйте и отметьте проверку человеком. Публикация доступна отдельной кнопкой.
7. В «Настройках» переключите проект тарифа: «Старт» закрывает расширенное продвижение и партнёров, «Рост» открывает продвижение, «Партнёры» открывает оба модуля. Платежей нет.

Кнопка «Как смотреть демо» вверху содержит встроенную инструкцию. Перед следующим показом: CRM → Настройки → Сбросить демо-данные.

## Что реализовано

- Сайт: услуги и состав работ, примеры объектов, процесс, форма с проверкой обязательных полей и телефона, FAQ, партнёрские предложения, отдельный экран услуги.
- CRM: канбан с шестью статусами и перетаскиванием, таблица, фильтры и поиск, карточка заявки и история, создание и повтор заказа.
- Расписание на день и неделю, назначение бригад с проверкой пересечения времени.
- Клиенты и объекты с редактированием, бригады с загрузкой, мобильное рабочее место бригадира, чек-листы, сжатые фото до/после и комментарии.
- Обзор с показателями из заказов за выбранный период.
- Продвижение: план материалов, подготовленные примеры ИИ, редактор, предпросмотр, статусы и отдельное подтверждение публикации, редактируемый список площадок.
- Партнёры: создание и редактирование, загрузка изображения, сроки, переключение активности, связанный показ на сайте, демо-статистика и плановая сумма размещений.
- Тарифы и сброс примеров. Роли руководителя, менеджера и бригадира.

## Границы демо

- Рабочая дата зафиксирована: **9 октября 2026 года**, чтобы заказы и баннеры оставались предсказуемыми на презентации. Дата видна в CRM. История новых действий использует текущее время в часовом поясе Иркутска.
- Контакты, компании и показатели демонстрационные. Фото интерьеров — иллюстрации, не доказательства выполненных работ. Начальные завершённые заказы содержат образцы фото.
- Роли переключают экраны; это не авторизация или защита данных. Сервер, синхронизация между компьютерами и внешние интеграции отсутствуют.
- Публикация контента меняет статус внутри прототипа. Реальный сайт, поисковые системы и сторонние площадки не подключены. SEO-экран имеет маршрут `#/uslugi/uborka-ofisov-irkutsk`; для настоящего индексируемого сайта понадобятся отдельные серверные URL и метаданные.
- Переход по партнёрскому баннеру открывает демонстрационный предпросмотр и считает клик; внешний сайт не открывается. Показы считаются один раз на баннер за загрузку прототипа, плюс начальные демо-значения.
- Загрузка: JPG/PNG/WebP до 8 МБ, до 3 фото каждого вида на заказ. Изображения сжимаются до 900 px для локального хранилища. Большой архив фото требует серверного хранения.
- Суммы тарифов и подключения — проект для обсуждения. Telegram, MAX и PWA перечислены как дополнительные варианты и не реализованы.

## UI и ресурсы

Использованы бело-голубая палитра, шкала отступов 4/8 px, единые радиусы и видимый фокус. На телефоне боковое меню сворачивается, канбан прокручивается внутри рабочей области. Анимации учитывают `prefers-reduced-motion`.

Фотографии: Unsplash. Шрифт: Manrope. Библиотеки: Tailwind CSS 4.1.10 и GSAP 3.12.5 / ScrollTrigger. Все ресурсы встроены в HTML, сетевых запросов при работе нет.
